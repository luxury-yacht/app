### Added

- Karpenter resources under Cluster → Resources when Karpenter APIs are discovered,
  with resource-specific table fields and rich overviews for NodePools, NodeClaims,
  and provider NodeClasses.

### Changed

- Improved keyboard support. Most of the app controls should now be accessible via keyboard.
  - `Tab / Shift+Tab` moves the focus within a region. The currently focused control is shown with a highlighted background color.
  - `Ctrl+Tab / Ctrl+Shift+Tab` switches regions. Switching regions shows a brief outline around the active region.
  - Press `?` to see all keyboard shortcuts for the current context.
