### Changed

- Improved keyboard control
  - Tab/Shift+Tab moves focus within a region. Currently focused control is shown with a highlighted background color.
  - Ctrl+Tab/Ctrl+Shift+Tab switches regions. Switching regions shows a brief outline around the active region.
  - Keyboard access to table row actions, tab Close controls, status popovers, and object-map actions, with guidance in Keyboard Shortcuts help.
